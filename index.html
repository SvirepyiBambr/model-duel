    How it calls Pollinations

    Each move is one request to POST https://gen.pollinations.ai/v1/chat/completions with the visitor's key, the chosen model id, the board as text and a strict JSON instruction ({"column":0-6,"comment":"..."}). Illegal moves are rejected and re-asked once; the winner is computed by the referee, not by the model. See app.js.
